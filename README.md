# Finance Dataset Analysis | Power BI

## Project Overview
An interactive financial data analysis dashboard built using Microsoft Power BI. This project explores customer segments, product costs, supplier distribution, and transaction performance through five dashboard pages.

## Dashboard Pages
1. **Main Overview** — Account, customer and transaction KPIs, transaction count by region, transaction status distribution, and monthly transaction trends.
2. **Customer Analysis** — Customer joining trends, customer segment distribution, and segment-level comparisons.
3. **Product Analysis** — Product cost by category, supplier mix across categories, and product cost versus average selling price.
4. **Transaction Analysis** — Transaction volume by payment method, transaction type performance by month, transaction status by channel, and transaction amount versus benchmark.
5. **Insights & Summary** — Key findings, business recommendations, and project conclusions.

## Key Findings
- SMB is the largest customer segment, with 182 customers (36.4%).
- The dataset contains 50 products from 19 suppliers.
- Total transaction value is approximately 92.28M.
- Transaction status, payment method, regional distribution, and monthly trends provide opportunities for further analysis.

## Business Recommendations
- Monitor failed and pending transactions.
- Investigate monthly fluctuations in transaction values.
- Evaluate supplier distribution and product categories.
- Use interactive dashboard filters to explore customer and transaction patterns.
